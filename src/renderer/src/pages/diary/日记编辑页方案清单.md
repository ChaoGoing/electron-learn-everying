方案清单
A. 情感/感受类
1. 情绪轨迹图（Emotion Timeline）
- 形式：不是选一个"今天的心情"，而是按小时/时间段打点，一天一条折线/色带，自动算出"今天的高光时刻"和"低谷"。
- 编辑页：一条时间轴，拖动滑块选情绪 emoji（复用现有 MOODS），底部一句话总结。
- 乐趣点：年底能生成"全年情绪曲线"，看出哪个月最焦虑、哪个季节最开心。
- 成本：中。复用 MoodPicker，新增一个时间轴组件。
2. 情绪温度计 / 能量×心情二维图
- 形式：横轴"心情好→坏"、纵轴"精力高→低"，一个四象限点，落在"开心的累"和"疲惫的爽"这种区域。
- 编辑页：一个可点击的 2D 坐标纸 + 一句话。
- 乐趣点：比单选 emoji 更细腻，还能做散点趋势。
- 成本：低-中。
B. 结构化模板类（和你的图片卡片同族）
3. 问答/每日三问模板
- 形式：固定的几道题，比如"今天最好的事 / 今天想感谢谁 / 明天的第一要做"。
- 编辑页：表单，逐题填空，保存后是漂亮的卡片。
- 乐趣点：降低"不知道写什么"的阻力，容易坚持。
- 成本：低，几乎是纯前端模板。
4. 九宫格 / 一日时间轴（Time Block）
- 形式：把一天切成 9 宫格（或早中晚+时间段），每格一张小图/一小段文字；或者 24 小时时间轴，在格子上贴"what I did"。
- 编辑页：网格或时间轴，点击格子填内容，可拖拽排序。
- 乐趣点：视觉冲击强，回看很直观。
- 成本：中。
5. 清单式 / 完成度日记（Done List）
- 形式：不是写"我该做什么"，而是记录"今天我完成了哪几件小事"，可勾选 + 打分（1-5 星）。
- 编辑页：可添加条目的 checklist（Tiptap 已有 TaskList），每项带完成状态和小评分。
- 乐趣点：正向反馈强，适合"成就感"型记录。
- 成本：低，能直接站在现有 TaskList 能力上。
C. 多媒体类
6. 语音日记（Voice Memo）
- 形式：按住录音，生成一条波形 + 自动转文字（可用本地/系统语音识别，Electron 主进程可接 Web Speech 或本地模型）。
- 编辑页：录音按钮 + 波形播放条 + 可编辑的转写文字。
- 乐趣点：边说边记，适合没空打字的场景，回听自己的声音很有意思。
- 成本：高。录音、存储、转写都需要主进程 + 文件管理。
7. 照片墙 / 胶片相机日记（Photo Roll）
- 形式：一天多张照片，像胶片一样横排/网格排，每张可加一句"拍立得"式说明，可选滤镜/日期戳。
- 编辑页：网格拖拽排序，点图编辑说明，uploadImage 已可复用。
- 乐趣点：旅行、美食日必备。
- 成本：中。图片上传基建已存在，主要是多图 + 布局。
8. 自由画布 / 手账日记（Scrapbook Canvas）
- 形式：一张空白画布，可拖入图片、贴纸、涂鸦、文字块，像真实手账拼贴。
- 编辑页：自由块编辑器，拖拽 + 缩放 + 旋转 + 贴纸库。
- 乐趣点：最"个性化"，但复杂度最高。
- 成本：高。
D. 量化/数据类
9. 睡眠 / 饮食 / 运动 / 收支等量化日记
- 形式：几个数字输入（睡了几小时、走了多少步、花了多少钱）+ 自动折线图。
- 编辑页：表单卡片 + 周/月趋势图（可复用日历，做成热力图）。
- 乐趣点：数字本身会讲故事，回看趋势很有动力。
- 成本：中。表单简单，趋势图要引入图表组件。
10. 自动捕获日记（Auto-journal）
- 形式：自动记录当天天气、位置、正在听的歌、屏幕时长等，你只需补一句"当时在干嘛"。
- 编辑页：上半部分是只读的自动卡片（天气/定位/音乐），下半部分补文字。
- 乐趣点："零负担"记录，回顾时特别有"当时"的感觉。天气已有 WeatherPicker，可接真实天气 API。
- 成本：中-高（取决于接多少外部数据源）。
E. 交互/回顾类
11. 聊天式日记
- 形式：编辑页像一个聊天框，你和"过去的自己"或一个 AI 角色一问一答，聊天记录即日记。
- 编辑页：气泡式输入，自动上屏。
- 乐趣点：像发消息一样自然，能触发更多倾诉。
- 成本：中（纯 UI 变体）。
12. 年度回顾 / 词云 + 热力图
- 形式：把全年日记生成 GitHub 式热力日历 + 高频词云 + 情绪曲线，一键"年度报告"。
- 乐趣点：这是所有形式共同的"终极回看"功能，最能体现坚持的回报。
- 成本：中-高，但和日历组件强相关。
